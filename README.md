# موعِد — Mawid

نظام حجز مواعيد للعيادات والمجمعات الطبية في الخليج (Next.js 16).

| الصفحة | الوصف |
| --- | --- |
| `/` | الموقع التسويقي: المميزات، التخصصات، المقارنة، الأسعار، الأسئلة، طلب عرض عبر واتساب |
| `/demo` | تجربة حجز المريض (عيادات رِفق التجريبية) |
| `/dashboard` | لوحة العيادة: المواعيد، التقويم، المرضى، الأطباء، الخدمات، الإعدادات |

- بيانات التواصل (واتساب، الإيميل، الاسم) في `src/config/site.js`.
- بيانات التجربة في `src/lib/demo-store.js` وتُحفظ في متصفح الزائر فقط.

```bash
npm install
npm run dev
```
