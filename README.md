# موعِد — Mawid

نظام حجز مواعيد للعيادات والمجمعات الطبية في الخليج (Next.js 16).

| الصفحة | الوصف |
| --- | --- |
| `/` | الموقع التسويقي (أنيميشن، حاسبة خسارة الغياب، محاكاة واتساب، البوابات، الأسعار) |
| `/doctors` | بحث وفلترة الأطباء (تخصص، مدينة/حي، تأمين، سعر، تقييم، متاح اليوم، طبيب/طبيبة، عيادة/فيديو/منزلية) |
| `/doctors/[id]` | ملف الطبيب: الدور المباشر، التقييمات الموثّقة، التأمين، الباقات، والحجز بالساعة + الدفع/التقسيط |
| `/patient` | بوابة المريض: مواعيدي والدور المباشر، الملف الطبي، الروشتات PDF، العائلة والباقات، الإشعارات |
| `/doctor` | بوابة الطبيب: طابور اليوم، ملف المريض، روشتة إلكترونية بـ QR، الإجازات وخانات الطوارئ، الفيديو |
| `/reception` | الاستقبال: تسجيل الوصول، Walk-in، إلغاء/تأجيل جماعي، الخزينة والفواتير |
| `/queue` | شاشة الانتظار (تلفزيون الصالة) |
| `/dashboard` | الإدارة: التحليلات، الأطباء والأسعار، التأمين، الباقات، التقييمات، الرسائل |

- كل البيانات التجريبية في `src/lib/platform.js` وتُحفظ في متصفح الزائر (localStorage)، والبوابات مربوطة ببعض لحظيًا بين التابات.
- بيانات التواصل (واتساب، الإيميل، الاسم) في `src/config/site.js`.
- بيانات التجربة في `src/lib/demo-store.js` وتُحفظ في متصفح الزائر فقط.

```bash
npm install
npm run dev
```
